# Prometheus intro images

## Add the 25 images

1. Put all image files in the `images` folder.
2. Open `script.js`.
3. Replace the filenames inside the `images` array with your 25 filenames, in the order you want them to appear.
4. Keep the filenames and extensions exact, including `.jpg`, `.jpeg`, or `.png`.
5. Open or refresh `index.html` in the browser.

Example:
